# Portfolio Evidence Verifier Skill

## Overview
Analyzes linked code repositories to establish empirical proof of mastery for claimed languages and frameworks.

## Operations
1. Inspects repository codebase, commit frequencies, and project architecture.
2. Computes mastery confidence metrics (0% to 100%).
3. Generates verified evidence summaries for recruiter review.
