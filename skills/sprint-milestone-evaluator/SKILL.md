# Sprint Milestone Evaluator Skill

## Overview
Monitors progressive milestone submissions during employer-sponsored project sprints.

## Operations
1. Ingests candidate deliverables (PRDs, code pull requests, test suites).
2. Verifies delivery against sprint timelines and acceptance criteria.
3. Certifies completed sprints for portfolio badge issuance.
