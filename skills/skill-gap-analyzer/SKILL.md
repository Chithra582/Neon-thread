# Skill Gap Analyzer Skill

## Overview
Diagnoses unverified or missing skills required for targeted roles and constructs personalized learning-by-building roadmaps.

## Operations
1. Compares candidate profile against target job role specifications.
2. Identifies specific technological gaps (e.g., missing FastAPI or Docker evidence).
3. Recommends tailored sprint projects to turn theoretical knowledge into verified proof.
