# Talent Challenge Matcher Skill

## Overview
Evaluates the technical compatibility between a developer's verified skills and an employer's project challenge requirements.

## Operations
1. Ingests candidate verified skill vector and challenge required skills.
2. Computes overlap percentage and identifies missing requirements.
3. Generates concise, 2-sentence match rationales explaining candidate fit.
